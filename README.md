# White Cloud 2 website

Static site for White Cloud 2, 1252 S Walnut St #3, Starke, FL 32091.

- `public/index.html` is the whole site.
- `public/photos/` is for real product photos. Add `img:"photos/name.jpg"` to a product in the `CATS` list inside index.html.
- `server.js` is a zero-dependency Node server. Railway sets `PORT` automatically.

Run locally: `npm start`, then open http://localhost:3000
